# Project Rules

## Security

- **Запрет на автоматический запуск приложений**: Никогда не запускай приложения, скрипты, серверы или исполняемые файлы автоматически без явного разрешения пользователя. Всегда спрашивай перед выполнением команд типа `npm start`, `npm run dev`, `python app.py`, запуском серверов или любых других исполняемых процессов.
